# TickList v0.1.0 说明（待正式发布）

状态（2026-10-23）：v0.1.0 标签已建立，指向产品基准 9896044；应用 ZIP、校验文件及中文说明已保存为维护者草稿。源码仓库已公开，正式 Release 尚未发布，附件暂未开放下载。本轮视频及文档整理不移动现有标签。

TickList 是电脑端轻量待办网页，无需注册，使用普通 HTML、CSS 和 JavaScript，网页运行无需 Node 或安装依赖。

- 一行添加、任务详情与说明、截止时间和逾期提示。
- 全部/未完成/已完成筛选、鼠标手柄排序、删除后10秒撤销。
- 中英文、深浅色模式、JSON 备份恢复及 Markdown 导出。
- 超过5 MiB的备份先确认耗时，再继续读取恢复；无效内容或保存失败不会替换当前清单。

解压完整下载包后打开 landing.html 查看介绍，或打开 index.html 使用清单。保持 assets 目录与页面同级。LICENSE 是 MIT 代码许可，BRAND-LICENSE.md 是独立品牌与素材说明。

数据仅保存在当前浏览器。更换浏览器、文件位置或访问地址前，先下载 JSON，在新入口恢复；上传代码不会迁移清单，也没有云同步。多页冲突没有自动合并，建议一个页面编辑；排序依赖鼠标，不提供手机端适配承诺。

## 检查与离线素材

运行 node tools/prepare-upload.js --write 生成本地源码候选清单及素材摘要；工具不提交、推送或删除文件。全部公开 Markdown 的本地链接均参与检查，不再排除历史说明。

WAV/MP3 等实际制作输入按 media/asset-manifest.json 的摘要单独保存，不进入 Git；源代码单独检出不能完整渲染有声片，恢复相应素材后方可编辑和校验。原始来源 HTML 快照本地保存，其摘要仍由 source-manifest.json 追溯，不作为当前制作依赖。

应用 ZIP、视频、封面及两个校验文件已在 [v0.1.0 正式 Release](https://github.com/Aaron7510/TickList-Local-Todo/releases/tag/v0.1.0) 发布，实际下载和摘要核对通过；详见[正式发布验收](正式发布验收-2026-10-23.md)。

## 宣传视频下一步

建议先做 5 秒风格预览，确认品牌节奏和可读性，再制作约 40 秒、1920 × 1080、30 fps 的桌面宣传片。正式字标沿用 Segoe UI Bold，勾号作为品牌 IP，保留“把今天，一件件做好。”；先确定发布渠道与是否需要配音，再定最终比例和时长。

| 时间建议 | 内容 |
| --- | --- |
| 0–5 秒 | 勾号 Logo 与“今天要做什么，一眼就清楚。” |
| 5–14 秒 | 使用三条公开示例任务，演示一行添加与清晰列表 |
| 14–24 秒 | 独立手柄排序、设定截止时间、勾选完成与未完成筛选 |
| 24–32 秒 | 详情说明、深浅色与双语能力，控制展示密度 |
| 32–36 秒 | 简短展示“数据 / 导出”，说明本地保存、支持备份 |
| 36–40 秒 | 品牌标语与一个入口；实际网址上线后再替换占位 |

视频工程放在 marketing/video 下独立维护，视频工具与依赖待制作时核对，避免影响静态网页运行。使用正式 SVG 与代码构建界面，避免压缩截图放大；只展示示例任务。先输出低分辨率节奏预览，确认后再渲染成片；检查字幕、真实功能一致性、音画同步及素材授权。

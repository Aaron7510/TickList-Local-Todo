# TickList 多比例封面重建

适用于 [4:3 / 9:16](2026-10-23/README.md) 与 [3:4](2026-10-23-3x4/README.md)。现有 JPG、PNG 和文字转路径的 SVG 可以直接使用，查看不需要安装字体或开发工具。

以下 PowerShell 命令从仓库根目录执行。所有新输出放在被忽略的 `release-artifacts/`，不覆盖仓库原图、源设计或批准记录。使用另一组封面时，修改 `$coverSet`；每次运行需使用尚不存在的输出目录。

## 准备环境

验证环境为 Windows、Python 3.12、Node.js 24、Pillow 12.2.0、fontTools 4.63.0、Sharp 0.35.5。Python 依赖仅供重新生成设计使用；导出现有 SVG 只需要 Node 和 Sharp。

以下安装命令会下载依赖，并将其限制在本地工具目录；普通 TickList 网页不需要安装它们。

```powershell
$repoRoot = (Get-Location).Path
$coverTools = Join-Path $repoRoot 'release-artifacts/cover-tools'
if (Test-Path -LiteralPath $coverTools) { throw '工具目录已存在，请复用已核对的环境或另选新目录。' }
New-Item -ItemType Directory -Path $coverTools | Out-Null
python -m venv (Join-Path $coverTools '.venv')
if ($LASTEXITCODE -ne 0) { throw '创建 Python 环境失败。' }
$coverPython = Join-Path $coverTools '.venv/Scripts/python.exe'
& $coverPython -m pip install Pillow==12.2.0 fonttools==4.63.0
if ($LASTEXITCODE -ne 0) { throw '安装 Python 依赖失败。' }
npm.cmd install --prefix $coverTools --no-save --package-lock=false sharp@0.35.5
if ($LASTEXITCODE -ne 0) { throw '安装 Sharp 失败。' }
$env:SHARP_PATH = Join-Path $coverTools 'node_modules/sharp'
```

已有同版本环境时，可直接令 `$coverPython` 指向该 Python，并将 `$env:SHARP_PATH` 设为 Sharp 包的绝对目录。生成脚本从 PATH 查找 Node，也可通过 `NODE_BINARY` 指定其可执行文件。

## 方式一：导出现有 SVG

此方式不读取字体，也不需要原视频。复制仓库内已转路径的 SVG 和导出脚本到新目录，导出 PNG / JPG。

```powershell
$coverSet = '2026-10-23' # 3:4 改为 '2026-10-23-3x4'
$coverSource = Join-Path $repoRoot "marketing/video/covers/$coverSet"
$exportDir = Join-Path $repoRoot "release-artifacts/cover-export-$coverSet"
if (Test-Path -LiteralPath $exportDir) { throw '输出目录已存在，请另选目录。' }
New-Item -ItemType Directory -Path (Join-Path $exportDir 'source'), (Join-Path $exportDir 'public') | Out-Null
Copy-Item -Path (Join-Path $coverSource 'source/*.svg') -Destination (Join-Path $exportDir 'source')
Copy-Item -LiteralPath (Join-Path $coverSource 'source/render-covers.cjs') -Destination (Join-Path $exportDir 'source/render-covers.cjs')
node (Join-Path $exportDir 'source/render-covers.cjs') $exportDir
if ($LASTEXITCODE -ne 0) { throw '导出失败。' }
```

用当前目录的标准校验清单核对输出：

```powershell
foreach ($line in Get-Content -LiteralPath (Join-Path $coverSource 'SHA256SUMS.txt')) {
    $parts = $line -split '\s+', 2
    $imagePath = Join-Path $exportDir $parts[1]
    if ((Get-FileHash -LiteralPath $imagePath -Algorithm SHA256).Hash.ToLowerInvariant() -ne $parts[0]) {
        throw "输出摘要不匹配：$($parts[1])"
    }
}
```

在上述验证环境中，六张导出图片与仓库图片逐字节一致。更换渲染库或版本可能改变编码字节；原公开摘要仍以仓库现有图片为准。

## 方式二：从文字重新生成设计

此方式需要 Python 环境、Sharp 和本机合法安装的两种字体：`C:/Windows/Fonts/msyhbd.ttc`（微软雅黑粗体）与 `C:/Windows/Fonts/segoeui.ttf`（Segoe UI）。字体不随项目分发；缺少字体时需自行准备并适配脚本路径。现有 SVG 的使用不受影响。

生成脚本会读取原定版 MP4 和原 16:9 JPG 的摘要作为保护基线。干净 Git 检出不包含这两份媒体，需先从正式 Release 下载到以下位置。只补充缺失文件，已有文件仅核对，不覆盖。

```powershell
$approvedDir = Join-Path $repoRoot 'marketing/video/release/2026-10-19/public'
New-Item -ItemType Directory -Path $approvedDir -Force | Out-Null
$approvedFiles = @(
    @{ Name = 'TickList-Promo-35s-1080p60.mp4'; Sha256 = '207755f45c56c661b968fcb6537f8963e580750b1824303c01f0a4d0f890d8c4' },
    @{ Name = 'TickList-Promo-Cover-1920x1080.jpg'; Sha256 = 'c1ad31e740bf0f425f625dc02b51ca07d4fed209eb29a25387ac3489f90083f7' }
)
foreach ($item in $approvedFiles) {
    $mediaPath = Join-Path $approvedDir $item.Name
    if (-not (Test-Path -LiteralPath $mediaPath)) {
        Invoke-WebRequest -Uri ("https://github.com/Aaron7510/TickList-Local-Todo/releases/download/v0.1.0/" + $item.Name) -OutFile $mediaPath -ErrorAction Stop
    }
    if ((Get-FileHash -LiteralPath $mediaPath -Algorithm SHA256).Hash.ToLowerInvariant() -ne $item.Sha256) {
        throw "定版媒体摘要不匹配，停止重建：$($item.Name)"
    }
}
```

3:4 脚本还会核对仓库已有的 4:3 / 9:16 `public/` 图片，需保留完整源码检出。先准备空输出目录，只复制两个脚本，不复制已有 SVG，否则防覆盖检查会主动中止。

```powershell
$coverSet = '2026-10-23' # 3:4 改为 '2026-10-23-3x4'
$coverSource = Join-Path $repoRoot "marketing/video/covers/$coverSet"
$rebuildDir = Join-Path $repoRoot "release-artifacts/cover-rebuild-$coverSet"
if (Test-Path -LiteralPath $rebuildDir) { throw '输出目录已存在，请另选目录。' }
New-Item -ItemType Directory -Path (Join-Path $rebuildDir 'source') | Out-Null
foreach ($scriptName in @('build-covers.py', 'render-covers.cjs')) {
    Copy-Item -LiteralPath (Join-Path $coverSource "source/$scriptName") -Destination (Join-Path $rebuildDir "source/$scriptName")
}
& $coverPython (Join-Path $rebuildDir 'source/build-covers.py')
if ($LASTEXITCODE -ne 0) { throw '设计重建失败。' }
```

输出包括 SVG、JPG / PNG、QA 拼图、工作副本 manifest 和校验清单。工作副本的待审状态属于一次新生成的记录，不改变已发布素材的状态。可将方式一的摘要核对命令中的 `$exportDir` 替换为 `$rebuildDir` 验证图片；批准原件和旧 manifest 均不应被新结果覆盖。
